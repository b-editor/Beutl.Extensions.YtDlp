### 短い説明

```text
yt-dlp で動画・音声を検索・ダウンロードしてタイムラインに追加します
```

### 説明

```markdown
[yt-dlp](https://github.com/yt-dlp/yt-dlp) を使って動画や音声を検索・ダウンロードし、そのまま Beutl のタイムラインに追加できる拡張機能です。UI は日本語のみです。

## できること

- キーワードで YouTube と SoundCloud を検索し、サムネイル・長さ・再生回数付きの一覧から選べます。
- 動画の URL を貼り付けると、その動画を直接取得します。
- 最高画質、1080p まで、720p まで、音声のみなどの形式を選んでダウンロードできます。動画ごとに個別の形式も選べます。
- ダウンロードが終わると、再生ヘッドの位置にタイムラインへ追加します。
- ダウンロード履歴から、ファイルをタイムラインへ追加し直せます。
- yt-dlp は拡張機能の中からインストール・更新できます。

## 使い方

1. ツールタブの追加メニューから「yt-dlp」を開きます。
2. yt-dlp が見つからない場合は、タブに出る「インストール」を押します。
3. 検索欄にキーワードか URL を入力して Enter を押します。
4. 一覧の行にあるダウンロードボタンを押します。

## 動作要件

- Beutl 2.0.0-preview.8 以降
- FFmpeg（映像と音声の結合に使います。Beutl がインストールしたものを自動で検出します）

## 利用上の注意

- ダウンロードするコンテンツの著作権と、各サイトの利用規約は、ご自身の責任で確認してください。
- 権利者の許諾がないコンテンツや、利用規約でダウンロードが認められていないコンテンツはダウンロードしないでください。違法にアップロードされたものと知りながら著作物をダウンロードすることは、著作権法で禁止されています。
- yt-dlp と FFmpeg は同梱していません。yt-dlp はインストールを選んだときに GitHub の公式リリースから取得します。
```

## スクリーンショット

実際の Beutl で撮影したものを使います。次の 3 枚があると機能が伝わります。

1. 「検索」タブ：検索結果が並び、1 行がダウンロード中の状態
2. 行の形式を開き、動画ごとのフォーマットを選んでいる状態
3. 「履歴」タブ：素材フォルダーと保存先の履歴が並んだ状態

権利者の許諾がある動画や、自分でアップロードした動画を使って撮影してください。
